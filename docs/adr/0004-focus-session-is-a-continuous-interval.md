# Focus Session jest ciągłym przedziałem

Focus Session nie jest wielokrotnie pauzowanym rekordem: Pause kończy bieżący
przedział z jednym Context Checkpointem, a Resume tworzy nową sesję dla tego
samego Work Itemu. Większa liczba rekordów upraszcza historię czasu, awarie i
naliczanie Effort Budget oraz zachowuje relację najwyżej jednego checkpointu na
sesję.
