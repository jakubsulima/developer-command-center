# Workspace jest granicą danych od MVP

Mimo że MVP jest produktem jednoosobowym, każdy użytkownik otrzymuje prywatny
Workspace, a dostęp opisuje Membership. Wybraliśmy dodatkową strukturę teraz,
ponieważ późniejsze dodanie izolacji do istniejących danych, wyszukiwania,
integracji i kontekstu AI byłoby ryzykowne; funkcje zespołowe i przenoszenie
danych między Workspace'ami pozostają poza MVP.
