# Commitment zamiast generycznego Planu

W MVP nie istnieje generyczny Plan ani osobne plany dzienne, tygodniowe i
projektowe. Commitment dopuszcza jeden ukształtowany Project, Investigation albo
Learning Goal do aktywnego WIP i może zapisać opcjonalny Effort Budget; Today i Week są
projekcjami Commitments oraz Work Items. Ograniczamy w ten sposób konkurujące
listy kosztem braku osobnego modelu Cycle i rozbudowanego planowania kalendarza.
