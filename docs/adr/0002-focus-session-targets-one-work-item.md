# Focus Session realizuje jeden Work Item

Każda Focus Session wskazuje dokładnie jeden konkretny Work Item zamiast
bezpośrednio wskazywać szeroki Project, Investigation albo Learning Goal.
Minimalne doprecyzowanie akcji przed startem zwiększa tarcie, ale zapewnia
porównywalną historię sesji, użyteczne checkpointy i jednoznaczne wznowienie;
jeden Work Item może wymagać wielu sesji i wspierać kilka szerszych rezultatów.
